
# 1. Project Title
## HR Data Analysis using Power BI



## 2. Project Overview
HR data analysis project using Power BI covering workforce insights, salary analysis, performance evaluation, growth trends, and country-wise comparisons.
This project focuses on performing HR data analysis using Power BI to derive workforce insights from employee data.
The analysis covers employee distribution, salary trends, workforce growth, demographic analysis, employee filtering, and performance-based insights using interactive visualizations and Power Query transformations.


## 3. Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel
- Data Visualization
- Business Intelligence


## 4. Analysis Questions & Visualizations

## Q1. Department-wise Employee Count
Analyzed workforce distribution across departments to understand employee allocation within the organization.

## Q2. Gender Distribution by Department
Compared male and female employee representation across different departments.

## Q3. Age Distribution Analysis
Created histogram visualizations to understand employee age spread within the company.

QUESTION 4
## 4. Salary Analysis by Department
Calculated minimum, maximum, and average salary metrics across departments.

## Q5. Top Earners by Country
Identified highest-paid employees within different countries for comparative salary analysis.

## Q6. Company Growth Trend
Visualized employee growth trends over time to analyze workforce expansion.

## Q7. Employee Filter by Initial Letter
Implemented employee filtering functionality using starting characters for easier employee analysis.

## Q8. Salary vs Performance Analysis
Compared employee salary levels with performance ratings to identify performance-related salary patterns.


## 5. Data Cleaning & Transformation
The following preprocessing steps were performed using Power Query:
- Changed incorrect data types
- Split columns using delimiters
- Created conditional columns
- Extracted employee initials
- Cleaned inconsistent formatting
- Processed salary and joining date fields


## 6. Key Insights
- Workforce distribution varied significantly across departments.
- Procurement department showed higher male employee representation.
- Salary ranges differed noticeably between departments.
- Workforce growth increased steadily over time.
- Employee performance showed partial correlation with salary levels.
